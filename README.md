# CellProfiler pipelines for Cell Painting

Standard CellProfiler pipelines used by [Pharmbio](https://pharmb.io) at Uppsala University for Cell Painting image analysis: illumination correction, quality control, segmentation and feature extraction.

## Origin

These pipelines are adapted from the Broad Institute Imaging Platform's Cell Painting pipelines ([broadinstitute/imaging-platform-pipelines](https://github.com/broadinstitute/imaging-platform-pipelines)) and modified for our imaging setup.

## Citation

If you use these pipelines, please [cite]( https://doi.org/10.5281/zenodo.23416080) this repository.
